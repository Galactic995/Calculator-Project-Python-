# Calculator-Project-Python-
This is my First Python Project as a 12th grader learning Python for AI engineering
It asks the user for two nunbers (they can have decimals) and a operation (+, -, *, /, **, or square root) then prints the result.
I built this in order to practice using user inputs, text output, variables, and if/esle statements in Python.

# How to use
1. open 'calculator.py' in Pycharm, Python, or any other IDE for Python
2. Run the code
3. enter operation (+, -, *, /, **, or square root), enter first number, enter second number when prompted
4. see result in the console
